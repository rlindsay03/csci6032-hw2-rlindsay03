# Instructions for AI Coding Agents

- Work only inside this repository. Do not access or modify files outside it.
- Before reading or handling potentially sensitive material, and throughout the task, never read, print, store, commit, or upload secrets, credentials, private keys, browser data, or configuration files that may contain them.
- Before editing, explain the intended change and the files or areas it will affect.
- Ask for explicit approval before installing software, accessing a new network destination, deleting files, changing Git history, creating a commit, or pushing to a remote.
- Preserve all uncommitted user work. Avoid destructive Git commands, including force-pushes.
- Check `git status` before editing. If unrelated changes are present, stop and ask for guidance rather than proceeding.
- Make small, focused, reviewable changes.
- After editing, show `git diff` and run the smallest relevant test or verification command.
- Explain errors and failed checks explicitly; never silently ignore them.
- Never claim success without checking that the requested result was actually produced.
